对接教程

三步把信号台的采集接口接进你的 CMS。不同程序后台菜单略有差异，核心都是：粘贴接口地址 → 保存 → 点采集。

1
挑一个状态为「在线」的接口
在信号目录里优先选在线率高、30日均速小的接口；受限接口需先联系投稿人获取授权。
2
复制接口地址
进入接口详情页，点「复制接口」拿到原始地址；详情页同时提供适配对应 CMS 的完整采集地址（已拼好 ?ac= 参数）。
3
在 CMS 后台添加并采集
按下表找到你的程序对应的入口，粘贴地址保存，然后执行一次采集验证数据是否入库。

常见问题

  • 采集为空？先确认接口当前状态不是「离线」，再检查分类绑定是否已设置。
  • 提示 403 / 需要 Token？该接口为受限接口，在详情页找到「好心人」联系方式申请授权。
  • 速度慢？换 Top 10 里排名靠前的接口，或避开晚高峰采集。
  • 内容合规？本站仅收录接口信号状态，请自行确保所采集内容符合当地法规与版权要求。
教程不涉及任何付费服务。接口失效、参数变更，欢迎通过 GitHub Issue 反馈，维护者会更新 data.json。
