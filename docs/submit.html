投稿你的接口

本站没有后端、没有站内表单——所有接口都通过 GitHub Issue 投稿，公开透明、可追溯，也方便维护者合并进 data.json。

1
打开 GitHub 仓库的 Issues 页
点下方按钮直达，选择「新接口投稿」模板（New Issue → 接口投稿）。
2
按模板填写信息
必填：接口名称、接口地址、适配 CMS 类型；选填：是否受限 / Token 获取方式、期望署名（默认取你的 GitHub ID）。
3
等待巡检入库并署名
维护者验证可用后合并进目录，你的名字会出现在列表与详情页的「好心人」一栏，长期展示。
去 GitHub Issue 投稿 →
