微软正在升级其 Mixed Reality Link 应用，为 Meta Quest 3 及 Quest 3S 头显提供系统级的麦克风与摄像头串流支持。此次更新使头显设备可作为独立音视频输入源接入 Windows 11 系统。

![](https://cdn.neowin.com/news/images/uploaded/2026/09/1789793017_mixed_reality_link_app_windows_story.webp)

### **混合现实连接扩展**

通过该应用，Meta Quest 用户可将头显连接至 Windows 11 PC，构建多虚拟显示器工作空间。新版本突破原有显示与输入功能限制，将头显传感器数据直接暴露给操作系统。

### **音频设备整合**

系统识别新音频输入设备为”Mixed Reality Link Microphone”。用户可在语音通话或其他需麦克风权限的应用中调用 Quest 内置拾音器，摆脱对 PC 原生麦克风的依赖。

### **视频流媒体创新**

摄像头串流允许 Windows 应用获取头显视角画面，配合全新 Avatar Camera 功能，用户可选择 Meta 虚拟形象作为视频源，在保持身份标识的同时参与线上会议。

### **兼容性与部署**

功能搭载于 **version 26.9105.9070.0** 及以上版本。当前支持 Meta Quest 3/3S 与运行 Windows 11 version 22H2+ 的 PC 端组合。输入源将在系统设置中按以下名称呈现：

- Mixed Reality Link Microphone（音频输入）

- Mixed Reality Link Passthrough（摄像头输入）

- Mixed Reality Link Avatar Camera（头像视频流）
