微软向企业管理员发出正式通知，Edge 浏览器中的 IE Mode（Internet Explorer 模式）将在 2029 年被完全移除。

微软正在推进企业浏览器迁移计划，建议组织提前规划替代方案以确保业务连续性。

### **官方时间表确认**

根据微软发布的路线图，IE Mode 的支持将至少持续至 **2029 年**。在此之前，用户仍可启用该功能访问仅兼容旧版 Internet Explorer 的网站。

### **企业影响范围**

目前大量企业内部系统依赖 ActiveX、旧版插件等技术栈。这些应用在现代浏览器中无法正常运行，IE Mode 成为关键的过渡方案。

### **迁移建议**

微软建议 IT 团队尽早识别受影响的内部网站，优先改造核心业务应用。对于无法迁移的系统，需重新评估其必要性或与供应商协商升级方案。

### **技术背景说明**

Microsoft Edge 自 **2021 年** 起已逐步剥离 IE Mode 相关代码。虽然功能保留至今，但其维护优先级低于主流现代网页标准。
