微软宣布将 WinUI 从 Windows App SDK 中正式分离，并以 MIT 许可证将其完全开源。这一举措标志着 Windows 11 原生 UI 框架从”源代码可用”阶段进入真正意义上的开源生态。

### **许可证变更与代码开放**

此前 WinUI 虽在 GitHub 上提供源码，但受限于微软的专有许可证，开发者无法自由修改或重新分发。此次变更后，WinUI 采用与 .NET、PowerShell 等项目一致的 MIT 许可证，允许开发者自由使用、修改和分发代码。

### **技术架构调整**

WinUI 作为 Windows App SDK 的核心 UI 层，此前与 SDK 其他组件耦合发布。微软此次将其拆分为独立仓库，使开发者能够单独引用 WinUI 而不必依赖完整的 Windows App SDK，降低了项目依赖复杂度。

### **对开发者生态的影响**

真正的开源意味着社区可向 WinUI 贡献代码、修复 Bug 并推动功能演进。微软表示将接受符合规范的外部贡献，并持续维护代码审查与合并流程。这一策略与微软近年来对开源的拥抱态度一致。
