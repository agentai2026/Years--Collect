微软向公众发布了针对 Windows 11 25H2、26H2 和 26H1 版本的最新累积更新 KB5132057 与 KB5132265，重点包括全新的 Windows Search 界面、Magnifier 多显示器支持及 Xbox 模式优化。

![](https://cdn.neowin.com/news/images/uploaded/2026/03/1773497950_windows_11_update_promo_neowin_story.webp)

### **Windows Search 全新设计**

更新引入简化的搜索结果列表，提升性能与内存效率。用户可直接在搜索框完成暗色模式开关、蓝牙控制及屏幕亮度调节等操作。若连接 Android 设备，还可执行拨打电话或设置勿扰状态等 Phone Link 功能。

### **Xbox 模式快速设置入口**

在 Xbox 模式下，Gaming Task View 导航栏新增快捷设置面板，无需退出当前环境即可访问完整任务栏设置项。同时，26H1 版本优化了该模式下的桌面退出与电源选项访问路径。

### **Magnifier 增强功能**

放大镜应用现支持每屏幕独立缩放级别，配合快捷键 Ctrl + Windows + K 实现多显示器视图锁定。对比度切换默认启用深色主题以减少眩光，并保留原图中色彩还原能力。

### **安全性与企业级支持**

CPU 架构设备上的 TPM 初始化问题已修复，内存完整性保护扩展至更多合规设备。新增 IPv6 CLAT 支持使仅 IPv6 网络兼容传统 IPv4 应用，企业可通过组策略配置 CLAT 参数。

### **云重建恢复机制**

WinRE 环境支持通过 Windows Update 下载镜像自动重装系统，无需 USB 介质。IT 管理员可远程启动云重建流程，并选择数据擦除或安全清理模式。

### **其他重要更新**

文件资源管理器右键菜单支持自定义命令布局，任务管理器内存统计涵盖全部物理内存。Live Captions 新增屏幕阅读器音频过滤选项，Narrator 实现对 Microsoft 365 数学公式的多语言识别。
