## AI 驱动 MUD 互动小说游戏引擎

一个六层架构游戏生成引擎——**模型负责生成漂亮的文字，状态层负责记住真实的世界**。支持把**任意一本小说 txt** 转成可玩的互动世界，并提供 Web / HTML5 / 终端三种游玩形态。

下载地址：[https://github.com/top777/AI-Game-From-Story](https://github.com/top777/AI-Game-From-Story)

`┌─────────────────────────────────────────────────────────────┐
│  ① 表现层：Web 前端(移动端) / HTML5 静态游戏 / 终端 / API    │
├─────────────────────────────────────────────────────────────┤
│  ② 指令解析层：MUD 命令 + 自然语言意图 → 结构化动作           │
├─────────────────────────────────────────────────────────────┤
│  ③ 游戏状态层：世界真相的唯一权威（JSON + 存档/读档）         │
├─────────────────────────────────────────────────────────────┤
│  ④ 提示词组装层：System + 世界书 + 状态 + 滑动窗口 + 长期记忆 │
├─────────────────────────────────────────────────────────────┤
│  ⑤ 模型接口层：文本 LLM + 文生图/识图 + TTS/STT（云+本地）    │
├─────────────────────────────────────────────────────────────┤
│  ⑥ 小说抽取层：任意 txt → 类型化抽取 → 结构化世界书资产       │
└─────────────────────────────────────────────────────────────┘`
