微软发布 PowerToys 预览版更新，版本号升至 **0.101.2211.0**。本次更新为 Advanced Paste 引入 Phi Silica 本地 AI 模型支持，同时对 Command Palette、Mouse Jump 等组件进行了优化与修复。

![](https://cdn.neowin.com/news/images/uploaded/2025/12/1766746708_1685715624_15-fotor-20251226155719_story.webp)

### **Advanced Paste 新增本地 AI 支持**

Advanced Paste 功能迎来重要更新，新增对 Phi Silica 的支持。Phi Silica 是微软自研的小型本地语言模型，用户无需支付第三方 API 费用或配置 Ollama/Microsoft Foundry 即可本地运行 AI 功能。此外，该功能现支持按操作自定义，包括提供商选择及额外自定义操作。

### **Command Palette 与 Mouse Jump 优化**

Command Palette 在本版本中获得最多单项修复，主要集中在可靠性与性能提升，包括对话框处理、图标加载、内存清理、主题行为及停靠性能监控等方面。Mouse Jump 则完成了架构升级，从旧的 WinForms 界面迁移至 PowerToys 较新的 WinUI 架构，这是微软持续现代化各组件的又一进展。

### **其他功能改进**

- **窗口管理：**FancyZones、Grab And Move 及 Always On Top 的关闭行为得到改善，Always On Top 边框现以完全不透明度渲染

- **Keyboard Manager：**修复新版编辑器中提权运行程序的浏览流程

- **Settings：**新增更新通道选择器及引导式 Bug 报告流程，包含进度提示与 GitHub 快捷入口

- **Quick Accent：**长按激活机制优化，选择器仅在预期时出现

- **预览版本支持：**新增独立的预览版本版本控制与更新通道支持，使预览版可独立于稳定版发布与测试

### **后续更新**

发布仅一天后，微软又推送了 **0.101.2222.0** 版本，修复了 Settings 常规页面加载问题、Quick Accent 首帧空白问题，并扩展了 Image Resizer、Peek、文件资源管理器插件及 File Locksmith 的现代 UI 自动化支持。

本次发布的预览版本属于早期测试版本，需用户主动选择加入，不会通过微软应用商店推送。用户可从 [GitHub 页面](https://github.com/microsoft/PowerToys/releases/tag/v0.101.2211.0) 直接下载安装。
