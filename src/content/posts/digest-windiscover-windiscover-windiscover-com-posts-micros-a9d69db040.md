微软正式终止了对 Exchange Server 2016/2019 及 Skype for Business Server 2015/2019 的扩展支持计划。自 2026 年 4 月启动的付费第二期扩展支持已于近期结束，相关 Legacy 版本将不再获得安全补丁更新。

![](https://cdn.neowin.com/news/images/uploaded/2025/09/1758082776_microsoft_logo_neowin_1_story.webp)

### **受影响产品线范围**

涉及终止支持的产品包括 **Exchange Server 2016**、**Exchange Server 2019**、**Skype for Business Server 2015** 及 **2019**。扩展支持通过付费 ESU（Extended Security Updates）包提供，每期期限为六个月，本期于 2026 年 4 月正式启动后已结束。

![](https://cdn.neowin.com/news/images/uploaded/2025/09/1758082776_microsoft_logo_neowin_1_story.webp)

### **后续更新机制变更**

目前仅有 **Exchange Server Subscription Edition (SE)** 与 **Skype for Business Server Subscription Edition (SE)** 可继续接收更新。未来漏洞修复不再收录于 Microsoft Security Response Center (MSRC) 公开记录，官方亦不提供相关文档说明。

![](https://cdn.neowin.com/news/images/uploaded/2025/09/1758082776_microsoft_logo_neowin_1_story.webp)

### **迁移建议与替代方案**

微软建议客户尽快迁移至受支持的配置。第三方厂商如 0patch 提供有限的企业级补丁服务，但运行非官方代码可能存在合规风险。当前仍可通过购买过期 Period 2 获取本月补丁，但后续月份将无法持续更新。
