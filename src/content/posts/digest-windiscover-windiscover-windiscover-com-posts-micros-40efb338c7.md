微软 Defender 现已正式支持 Linux 桌面操作系统。此举标志着微软安全产品在跨平台领域的重大扩展，使 Linux 用户也能获得原生的 Defenders 保护能力。

![](https://cdn.neowin.net/wp-content/uploads/sites/98/2025/08/microsoft-defender-linux.png)

### **原生支持与集成**

新的 Defender for Linux 提供原生守护进程（Agent），能够与 Linux 发行版的安全生态深度集成。该 Agent 负责监控威胁、扫描文件并执行防护策略，无需依赖第三方安全解决方案。

### **支持的发行版本**

当前已确认的支持范围包括 Ubuntu、Debian、CentOS 及 Red Hat Enterprise Linux 等主流企业级发行版。微软表示将持续扩展兼容列表以满足更多用户需求。

### **管理端配置**

所有受保护的 Linux 设备将通过 Microsoft Defender for Endpoint 管理中心进行集中管控。管理员可统一配置策略、查看合规状态并响应潜在威胁事件。

### **部署方式**

用户可以通过 Microsoft WSL (Windows Subsystem for Linux) 界面获取相关信息，或在 Linux 终端使用官方脚本完成 Agent 安装与注册流程。

### **产品战略意义**

此次功能扩展反映了微软在混合云与跨平台环境下的安全布局，有助于提升其安全产品线在不同操作系统生态中的竞争力。
