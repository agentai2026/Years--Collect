微软发布了适用于 Windows 11、Windows 10 及 Windows Server 的 Microsoft Defender 更新包，版本号升级至 **1.455.50.0**。该更新包用于更新系统安装镜像（WIM、VHD 及 ISO）中的反恶意软件客户端、引擎及签名文件。

![](https://cdn.neowin.com/news/images/uploaded/2025/06/1750541509_microsft_defender_neowin_story.webp)

### **更新内容与版本信息**

本次更新包将安装镜像中的安全组件升级至以下版本：

- 平台版本：**4.18.26070.9**

- 引擎版本：**1.1.26070.7**

- 安全情报版本：**1.455.50.0**

### **适用范围**

该更新适用于以下 Windows 版本的安装镜像：

- Windows 11

- Windows 10 ESU（扩展安全更新）

- Windows 10 Enterprise LTSC 2021

- Windows 10 Enterprise LTSC 2019

- Windows 10 Enterprise LTSB 2016

- Windows Server 2022

- Windows Server 2019

- Windows Server 2016

### **安全价值**

安装镜像中集成的 Microsoft Defender 组件可能因镜像制作时间较早而包含过时的安全定义，导致新系统部署后存在临时安全风险。该更新包通过预置最新反恶意软件定义，在系统安装阶段即可提供当前威胁环境所需的防护能力，消除部署初期的安全空窗期。
