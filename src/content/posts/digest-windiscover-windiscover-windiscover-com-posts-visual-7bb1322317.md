Visual Studio Code 1.136 版本正式推出 Agent Merge Preview 功能，允许 AI代理在拉取请求中自动创建代码分支和提交记录。此次更新聚焦于自动化工作流优化，提升开发者协作效率。

![](https://storage.windiscover.com/files/vscode-cover.png)

### **核心功能与操作方式**

新推出的 Agent Merge 功能支持 AI驱动的代码管理流程。当开发者发起拉取请求时，AI代理可自动创建对应的分支并完成相关提交，显著减少手动操作时间。

### **技术实现细节**

该功能基于 VS Code 内置的智能分析引擎运行，能够识别代码变更模式并生成最优合并方案。测试数据显示，在典型开发场景中平均节省 **40%** 的时间成本。系统提供完整的审计日志以追踪每个自动化步骤的执行记录。

### **企业级应用价值**

对于使用 Azure DevOps 的团队而言，此特性大幅简化了代码审查流程。管理员可通过集中式控制面板监控所有自动化分支的动态状态，确保代码合规性与版本追溯性。
