微软确认 PowerShell 7 将成为下一个 Windows 版本的默认命令行工具，取代目前需要手动安装的旧版 PowerShell。

![](https://cdn.neowin.com/news/images/uploaded/2026/11/1794954826_1731983116_ps_full.webp)

### **双版本共存机制**

根据微软官方公告，PowerShell 7 与当前的 Windows PowerShell 5.1 将并行运行。依赖现有脚本和自动化的系统任务将继续使用 PowerShell 5.1，用户可随时迁移至新版本。

### **技术架构差异**

Windows PowerShell 5.1 是基于 .NET Framework 构建的旧版平台，超过 10 年未引入新功能。PowerShell 7 则是面向跨平台的现代版本，目前已更新至第 7 个主要点版本。

### **兼容性挑战与进度**

新版将通过 MSIX 包形式交付，相比传统 MSI 安装器存在一定限制。微软正在 GitHub 上追踪兼容性问题，预计未来迭代中将逐步解决。

### **推送时间与版本预期**

微软表示该功能将在下一个 Windows 版本上线，可能是 27H1 或 27H2 功能更新，但尚未明确具体版本号。
