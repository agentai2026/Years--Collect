微软宣布一项将影响管理员的重要变更，SharePoint Server 通过 iOS 和 Android 独立应用的访问将于 2026 年 11 月 27 日起停用。从该日期开始，应用将仅支持 SharePoint Online。

### **停用时间与适用范围**

本次停用面向全球所有客户，包括处于 GCC、GCC High 和 DoD 环境的组织。

### **受影响用户的应对建议**

对于受影响的组织，微软建议采取两项措施：首先通知通过 SharePoint 移动应用访问 SharePoint Server 的用户，其次更新内部文档和支持材料。

### **信息来源与背景**

此次更新通过 Microsoft 365 Message Center 发布，消息 ID 为 **MC1528013**。目前仅有一版 SharePoint Server 可用，即 SharePoint Server Subscription Edition (SE)。SharePoint Server 2016 和 2019 已于 2026 年 7 月 14 日终止扩展支持。

### **长期影响考量**

SharePoint SE 于 2021 年发布，微软表示将持续支持至 2035 年底。移动端支持的移除令仍选择服务器版本的组织对其长期支持产生疑虑。
