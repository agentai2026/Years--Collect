微软已正式发布 Windows 11 版本 26H2 的 ISO 镜像下载链接，面向需要 USB 安装的独立用户提供完整系统映像文件。本次更新对应 KB5129195 累积更新，构建版本为 **26300.9457**，除直接下载外也可通过 Media Creation Tool 获取。

### **ISO 镜像下载地址**

官方提供了两种架构版本的直链下载，有效期为 **24 小时**：

- **AMD64 PC**（Intel / AMD 处理器）：Windows11_Client_x64_en-us_26300_9457.iso

- **Arm64 PC**（高通 Snapdragon 处理器）：Windows11_Client_arm64_en-us_26300_9457.iso

### **企业评估版本**

企业或商务用户在部署前可通过官方评估 ISO 进行免费试用，测试周期为 **30 天**，期间无需激活验证即可使用全部功能。该方案适用于生产环境前的兼容性验证流程。

### **Media Creation Tool 版本说明**

媒体创建工具（Media Creation Tool）仍维持 **10.0.26100.7019** 版本号，内置最新 Windows Defender 更新日期同步。用户可通过微软官网的 Create Windows 11/Windows 10 Installation Media 区域下载该工具，其自动从 Windows Update 服务器拉取 KB5129195 构建的完整映像。
