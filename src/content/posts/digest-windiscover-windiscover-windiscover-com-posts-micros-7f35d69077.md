微软正式向 IT 管理员发出提醒，Windows Server 2012 和 Windows Server 2012 R2 已结束扩展支持期。自此日期起，这些版本的操作系统将不再接收安全更新或技术支持。

### **支持周期结束时间**

Windows Server 2012 的标准支持已于 2018 年 1 月 9 日终止，扩展支持已于 2023 年 1 月 10 日结束。此后，任何新版本的安全补丁均不会应用于这些系统。

### **安全风险与影响**

继续运行已过支持期的服务器将面临严重的安全风险。零日漏洞将无法获得补丁，不符合合规要求的企业环境可能面临监管处罚，且无法享受任何微软官方技术支持服务。

### **升级建议路径**

微软推荐用户尽快迁移至受支持的版本，包括 Windows Server 2016、2019、2022 及最新的 2025 版本。对于采用云服务的组织，可考虑转向 Azure 云基础设施以获取持续更新和维护保障。

### **替代方案选项**

部分用户选择延长支持协议（ESU）作为临时过渡方案，但该方案需额外付费且仅能提供有限的保护窗口。长期来看，完整的现代化迁移仍是唯一可持续的路径。
