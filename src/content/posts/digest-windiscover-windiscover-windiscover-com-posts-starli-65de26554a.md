另一个由 AI 辅助开发的免费 Microsoft Office 替代品 Starling OpenOffice 已正式发布，同时配套的 Starling Desktop 桌面环境也同步推出。

![](https://cdn.neowin.com/news/images/uploaded/2026/10/1792224283_starling_desktop_story.webp)

### **三大组件功能详解**

新套装包含 Writer、Sheets 和 Slides 三款应用，分别对应 Word、Excel 和 PowerPoint 功能。Writer 支持样式、列表、表格、图片、页眉页脚及拼写检查；Sheets 可处理公式计算、数字格式化、排序和自动求和；Slides 支持布局、形状、演讲者备注、幻灯片浏览器和演示文稿播放。

![](https://cdn.neowin.com/news/images/uploaded/2026/10/1792224277_starling_writer_word_processor.webp)

### **文档兼容性与浏览器支持**

支持 DOCX、XLSX 和 PPTX 文件格式，保证与现有文件的兼容性。最大亮点在于无需安装 Starling Desktop 即可使用，用户可直接在浏览器中启动 Writer、Slides 和 Sheets 三项组件。

![](https://cdn.neowin.com/news/images/uploaded/2026/10/1792224266_starling_sheets_excel.webp)

### **跨平台部署方案**

Starling OpenOffice 支持 Windows、macOS 和 Linux 三大主流操作系统。Windows 用户可通过 GitHub Release 页面下载便携版 ZIP 包，解压后运行 OfficeApp.exe 获得完整体验。由于 Windows 构建版本尚未签名，首次启动时可能触发 Windows Defender SmartScreen 安全警告。

![](https://cdn.neowin.com/news/images/uploaded/2026/10/1792224272_starling_slides_power_point.webp)

### **当前版本限制与未来规划**

目前处于早期发布阶段，仍存在功能局限，例如幻灯片播放默认在 Slides 窗口内运行而非全屏模式。项目网站设有兼容性对比页面，用于检测文档格式与 Microsoft Office 的视觉差异。完整项目托管于 GitHub，Starling Desktop 还可在 Windows 系统内通过 WSL 2 运行的 Ubuntu 容器中部署。
