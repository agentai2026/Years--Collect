微软正对 Windows 11 和 Windows Server 2025 的驱动程序签名策略进行调整，提高合规标准并加强对未签名驱动程序的管控。

### **新政策的核心变化**

此次调整主要涉及驱动程序加载时的验证机制升级。系统将更严格地检查驱动程序的数字签名完整性，包括证书链的有效性和发布者身份的可信度认证。

### **实施范围与对象**

新规影响面向消费者和企业的所有 Windows 11 设备以及运行 Server 2025 的服务器环境。已部署的系统将在收到组策略更新后逐步执行新的验证流程。

### **受影响的用户群体**

使用第三方硬件外设或测试版驱动程序的用户可能面临兼容性提示。微软提供了标准的回退路径，允许在特定场景下通过安全启动设置临时加载未签名驱动。
