Microsoft Edge 将正式终止对 Windows Information Protection (WIP) 和 Microsoft Defender Application Guard (MDAG) 的支持，企业管理员仅剩下 7 天时间完成迁移。这一变动将在 Microsoft Edge 154 版本发布后全球生效。

![](https://cdn.neowin.com/news/images/uploaded/2026/09/1788420043_microsoft_edge_logo_2019_story.webp)

### **停用时间与影响范围**

从 Microsoft Edge 154 版本开始，包括 Edge for Business 在内的所有版本都将不再支持这两项旧版保护功能。受影响的组件已从 Windows 11 中移除，此次 cutoff 主要针对 Windows 10 商业部署中手动启用这些遗留保护的系统。微软承认受影响规模相对较小，但仍需相关管理员尽快采取行动。

### **MDAG 退役历程**

过去几年中，微软一直在逐步移除 Microsoft Defender Application Guard。2023 年底退休了对 Office 应用的支持，一个月后对 Edge 采用相同措施。2024 年 4 月从 Edge 和其他浏览器商店移除该服务，Windows 11 24H2 则彻底移除了相关功能。此次 Edge 停用将是 MDAG 的最后阶段。

### **官方替代方案**

微软建议企业采用新的防护组合来替代已停用的功能：

- 针对 WIP 场景：使用 Microsoft Purview Information Protection、Microsoft Purview Data Loss Prevention (DLP)、Endpoint DLP 以及 Intune app protection policies

- 针对 MDAG 场景：使用 Microsoft Edge 内置的安全能力及其他适合环境的隔离解决方案

### **管理员行动建议**

标准用户若未启用这些策略不会察觉任何变化。受影响的企业管理员需要在本周内审查 Edge 和 Windows 10 的安全配置，确保不再依赖 WIP 和 MDAG。如需更多迁移时间，应联系微软支持或账户团队讨论选项。拥有 Message Center 访问权限的管理员可查阅 MC1459132 公告获取详细说明。
