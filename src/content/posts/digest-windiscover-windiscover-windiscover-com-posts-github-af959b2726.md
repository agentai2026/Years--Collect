GitHub Copilot 现已支持与 Microsoft Teams 深度集成，允许开发者在聊天对话中直接调用 AI 编程助手编写代码、创建 Pull Request 并完成部署流程。该功能目前处于公开预览阶段，支持 1 对 1 聊天、群聊、会议聊天及频道等多种场景。

![](https://cdn.neowin.com/news/images/uploaded/2026/08/1787343673_chatgpt_image_aug_22,_2026,_01_19_31_am_story.webp)

### **集成背景与设计初衷**

微软指出，软件开发中的编码与架构问题通常会在 Teams 聊天中进行讨论。开发团队经常在对话中诊断问题、商定解决方案及部署策略。通过将 GitHub Copilot 嵌入 Teams，开发者无需切换到独立的编码环境、手动提供完整上下文给 AI 代理，便可在对话中直接完成从讨论到代码实现的流程。

### **使用方法与核心功能**

用户在 Teams 中安装 GitHub 应用后，可通过 **@** 提及方式调用 GitHub Copilot。AI 工具将自动结合对话上下文与代码仓库信息，基于商定的解决方案创建 Pull Request。主要功能包括：

- 基于 Teams 对话中讨论的需求构建功能

- 实现 Bug 修复

- 扩展测试覆盖率或改进文档

- 创建和更新 Pull Request

### **权限控制与人工审核**

微软已确认 GitHub Copilot 将遵守所有现有权限设置，包括与代码仓库相关的访问控制。尽管 AI 工具可减少人工操作负担，但代码审查与批准环节仍需人工介入，以确保开发流程的可控性。

### **后续计划**

目前该集成功能正处于公开预览阶段，微软尚未公布正式推出的具体时间表。
