微软正在为 Excel 引入基于 Copilot 的全新交互式画布功能，允许用户将电子表格数据快速转化为视觉化动态报告。该功能通过与原始工作簿的数据关联实现自动同步更新，大幅简化了仪表板制作流程。此外，微软还公布了多项配套的 Copilot 增强特性，包括技能构建器和数据清洗工具。

![](https://cdn.neowin.com/news/images/uploaded/2026/10/1791824103_microsoft_excel_copilot_interactive_canvas_story.webp)

### **交互式画布与动态关联**

交互式画布允许用户通过简单提示将 Excel 工作表数据转化为视觉吸引力的互动报告。Copilot 可基于现有工作簿数据创建高层级综述、项目进度更新或状态报告。由于生成的画布与工作簿保持连接，当底层数据发生变化时，报告会自动更新以反映最新信息。如果用户对初始结果不满意，还可请求调整布局、突出不同洞察或更改信息呈现方式，而无需重新构建整个报告。

### **技能构建器与技能录制器**

Microsoft 推出了 Skill Builder 和 Skill Recorder 功能以减少 Excel 中的重复性手动操作。Skill Builder 允许用户通过对话描述工作流程、提供指令、分享过往提示或提供已完成工作的示例，Copilot 将其转换为可重复使用的技能。对于无法清晰描述工作流的用户，可使用 Skill Recorder 记录操作过程，Copilot 会将 Excel 中执行的操作转换为可再次执行的复用技能。Skill Builder 预计于 **10 月**全面推出，Skill Recorder 则将于 **10 月底**面向 Insiders 推送。

### **数据导入与清洗功能升级**

微软改进了 Excel 中的数据导入与准备体验。全新的 Get Data 功能允许用户描述所需数据的来源及结构，替代原有的 Power Query 查询创建方式。Clean Data 功能可识别常见数据质量问题，如重复记录、格式不一致、数据类型错误等。例如，系统能检测同一列中出现 “USA”、”US” 和 “United States” 的情况并提供修正建议。Get Data 预计于 **10 月中旬**通过 Excel for the Web 全面发布，Clean Data 也将于 **10 月**启动推送。

### **当前可用性与受众范围**

交互式画布功能目前仅对 Microsoft 365 Insiders 用户开放。值得注意的是，微软此前已终止了在 Excel 单元格内直接调用 AI 的 COPILOT 功能，转而推出可复用技能和变更历史等改进方案以提升整体协作体验。
