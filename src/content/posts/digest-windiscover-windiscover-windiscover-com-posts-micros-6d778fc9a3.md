微软已将沿用数十年的 Telnet Client 列为已弃用功能，并计划在未来 Windows 版本中彻底移除。该工具自 1969 年推出，因缺乏加密机制已被更安全的 SSH 取代。

![](https://cdn.neowin.com/news/images/uploaded/2026/11/1795659651_telnet_client_full.webp)

### **历史背景与技术缺陷**

Telnet 协议诞生于 **1969 年**，早于微软公司成立年代。作为早期的远程访问技术，它允许通过命令行远程连接计算机。但该协议默认不加密传输数据，导致用户名和密码等敏感信息暴露风险极高。

![](https://cdn.neowin.com/news/images/uploaded/2026/11/1795659651_telnet_client_story.webp)

### **被 SSH 取代的技术演进**

随着网络安全需求提升，SSH 协议成为主流替代方案。如今 Telnet 仅存在于两类场景：老旧网络设备管理维护，或网络连通性故障排查。微软表示该决策旨在推动更安全的远程通信标准普及。

### **实施时间表与替代方案**

微软未在官方公告中给出具体移除日期，仅在 **11 月**发布的 Windows 已弃用功能列表中列入该工具。建议用户使用 Microsoft Store 或 PowerShell 获取 SSH 客户端作为替代方案。

h3>**行业影响分析**
此举反映操作系统对安全协议的强制升级策略。企业级环境中仍在使用 Telnet 的管理员需尽快完成迁移，否则将面临未来兼容性问题。
