微软正在推进 Microsoft Edge 浏览器对原生 XSLT（Extensible Stylesheet Language Transformations）支持的全面移除计划。该功能将在 2026 年 12 月中下旬开始默认禁用，预计 2027 年夏季彻底退出浏览器环境。

![](https://cdn.neowin.com/news/images/uploaded/2026/10/1791454877_edge_story.webp)

### **XSLT 技术背景与现状**

XSLT 是由万维联盟于 1999 年推荐的 XML 转换语言，用于将 XML 文档转换为 HTML 等格式。根据微软消息中心通告，当前全球网页中使用率仅为 **0.02%**，实际执行 XSLT 转换的比例不足 **0.001%**。

### **分阶段禁用时间表**

自 **Edge 159 版本**（2026 年下半年发布）起，XSLTProcessor JavaScript API 及引用 XSLT 样式的 XML 指令将默认关闭。IT 管理员可通过设置 **XSLTEnabled 策略** 为 true 临时延长支持，但该功能将在 **2027 年夏季 Edge 176 版本** 中彻底移除。

### **安全影响与技术替代方案**

由于 XSLT 存在重大安全风险且现代替代方案已成熟，微软建议组织通过 Edge 内置的 Lighthouse 工具审计受影响网站。对于自有站点应迁移至新标准，外部站点需联系开发者更新配置。引用 CSS 样式表的 XML 指令不受此影响。
