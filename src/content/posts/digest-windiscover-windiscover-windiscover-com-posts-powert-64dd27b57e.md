微软推出 PowerToys 预览版本 **0.101.2211.0**，重点在 Advanced Paste 中集成 Phi Silica 本地 AI 模型。Phi Silica 是微软开发的端侧小语言模型，用户无需配置第三方 API 或搭建本地推理环境即可免费使用。该功能为处理文本粘贴等场景提供智能化支持，同时 Advanced Paste 新增更多自定义动作选项，支持按动作选择 AI 提供商。

![](https://cdn.neowin.com/news/images/uploaded/2025/12/1766746708_1685715624_15-fotor-20251226155719_story.webp)

### **Command Palette 与界面优化**

最新版本对 Command Palette 进行多项可靠性改进，包括优化对话框处理机制、图标加载性能、内存清理逻辑、主题适配行为及停靠性能监控能力。Mouse Jump 组件完成架构升级，从旧版 WinForms 界面迁移至 PowerToys 统一的 WinUI 架构。微软持续推进各组件现代化改造，提升界面一致性与交互体验。

### **窗口管理与键盘功能**

FancyZones、Grab And Move 及 Always On Top 三大窗口管理工具均优化了关机行为逻辑，Always On Top 的置顶边框现以完全不透明方式渲染。Keyboard Manager 修复了新版编辑器中提升权限运行程序的浏览流程异常问题。

### **Quick Accent 与设置改进**

Quick Accent 组件改进长按激活机制，确保仅在预期场景下弹出选择器，避免误触发。设置应用新增更新通道选择器，并引入引导式 Bug 报告流程，包含进度提示及 GitHub 快捷入口。预览版本现已支持独立版本号与更新通道管理，便于与稳定版并行测试。

### **后续更新动态**

微软在后续两天连续推送 **0.101.2222.0** 及 **0.101.2241.0** 版本，修复设置页面加载、Quick Accent 首帧渲染、Image Resizer 等组件的 UI 自动化问题，以及 Mouse Highlighter 高频输入稳定性等多项细节。当前预览版本需通过 GitHub 页面手动下载安装。
