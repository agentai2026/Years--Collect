### 功能介绍

-
**老师登录 + 访客浏览**

老师账号在 `data/config.json` 预设，登录后可管理自己创建的所有班级；访客（学生/家长）在「学生查询」页输入学号或扫自己本子上的二维码，只能看到该学生自己的作业情况。

-
**班级 → 学科 → 学生**

创建班级（一级）、学科（二级）、添加学生（三级，姓名+学号）；学生可调班。

-
**二维码贴纸 PDF**

按 班级+学科 生成每位学生的加密二维码，A4 每页 6×8=48 张，码下带姓名/学号，裁剪线清晰，打印后贴到学生本子上。二维码内容为加密后的「V1|班级|学科|学号」，只有配置了相同密钥的系统能解密。

-
**扫码收作业**

老师发起作业后，在作业页用浏览器摄像头批量/单次扫码。扫码成功自动标记“已上交”并全屏+声音反馈；重复扫码有明确提示且不重复计数；也可手动输入学号或点击名单状态快速改为 未交/已上交/已完成。

-
**报表统计**

① 作业报表——某个作业谁没交（未交名单）；

② 按学科统计——各学科作业数、上交率；

③ 按学生统计——每个学生应交/已交/完成率和排名。

### 安装与运行

要求 Python 3.9+（已在 3.11 验证）。

`pip install -r requirements.txt
python app.py`
启动后访问：

`http://localhost:5098`
局域网内手机访问：

`http://本机IP:5098`
默认账号：`admin / 123456`

演示账号：`demo / 123456`

部署到有公网域名的服务器时，建议在服务器端用 Nginx/Caddy 等配置 HTTPS（见下方摄像头说明）。

首次部署请务必修改默认密码，并把 `qr_aes_key` 改成自己的随机字符串。

### 演示数据（对外展示用）

内置一键生成脚本，造好 3 个班级、135 名学生、76 个作业和近 3000 条提交记录的“真实感”数据，方便演示宣传：

`python make_demo.py            # 首次生成
python make_demo.py --force    # 删除旧演示班级后重新生成`
演示账号：`demo / 123456`（王老师，拥有全部演示班级）

- 班级：初一(1)班 45 人 / 初二(3)班 42 人 / 高一(2)班 48 人，各 5 门学科

- 每学科 4~6 个作业分布在最近 30 天，每学科最新一个为“进行中”，打开即可现场扫码演示

- 上交率 80%~95%，部分标记“已完成”，含扫码次数与时间；随机种子固定，多次生成结果一致

- 同时生成初一(1)班全部学科的二维码贴纸 PDF（`data/演示数据/` 目录），可直接打印展示

### 移动端适配

界面为移动优先设计（手机竖屏体验最佳）：底部导航栏、表格自动变卡片、扫码面板吸顶、大按钮触控。电脑浏览器同样完整可用，登录页可直接手机访问。
