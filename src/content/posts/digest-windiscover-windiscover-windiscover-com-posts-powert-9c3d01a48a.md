微软发布 PowerToys **0.101** 版本更新，正式引入全新工具 Windows Hopper，并对设置更新机制、Command Palette 等多个模块进行重大改进。本次更新包含数十项功能增强与问题修复，现已向用户推送。

![](https://cdn.neowin.com/news/images/uploaded/2023/06/1685715597_10_story.jpg)

### **Windows Hopper：同应用多窗口快速切换**

Windows Hopper 是本次更新的核心功能，允许用户在同一个应用程序的多个窗口之间快速跳转。与 Windows 原生的 Alt + Tab 全局窗口切换不同，该工具专注于单个应用的多实例场景。例如当用户同时打开多个 File Explorer 窗口时，可通过可配置的 Alt + 反引号（`）快捷键在这些窗口间循环切换，提升多任务处理效率。

![](https://cdn.neowin.com/news/images/uploaded/2026/08/1787649351_screenshot_2026-08-25_141327.webp)

### **设置更新体验重构**

微软对 PowerToys 的更新机制进行了重新设计。用户现可在**设置 > 常规 > 更新频道**中选择 Stable（默认）或 Insider 分支。预览版本现已明确标注，且托管设备可通过组织策略控制预览更新权限。更新流程本身也得到优化，可清晰追踪并显示每个步骤的状态。

![](https://cdn.neowin.com/news/images/uploaded/2026/08/1787649723_screenshot_2026-08-25_142123_story.webp)

### **Command Palette 多项增强**

Command Palette 引入紧凑模式（默认关闭），仅在用户输入时展开显示匹配结果。用户可通过方向键或 Tab 键展开完整界面，搜索结果需要详细信息时会自动展开。其他改进包括：搜索排名优化与渐进式图标加载提升响应速度；改善背景切换、图标加载与扩展资源管理以增强稳定性；Dock 支持自动隐藏并集成时钟与通知中心入口；扩展可发送带自定义位置、图标和操作按钮的富通知；新增磁盘活动指标与更清晰的网络带宽显示；支持深度链接直达扩展安装页；以及 Windows 等待重启时显示”更新并重启”和”更新并关机”命令。

### **WinUI 3 现代化迁移与其他功能**

Quick Accent 与 Mouse Jump 已完成向 WinUI 3 的迁移，带来大量 UI 与交互改进。PowerDisplay 工具新增关联亮度功能，可同时调节多显示器亮度。其他亮点包括：Advanced Paste 支持本地 AI；Shortcut Guide 新增 Windows 键激活方式；ZoomIt 增加 DemoMirror、摄像头背景模糊、麦克风降噪与录制亮度控制；Mouse Highlighter 新增 Ripple 模式。
