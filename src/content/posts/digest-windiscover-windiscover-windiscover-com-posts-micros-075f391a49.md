微软近期向 IT 管理员推送了多项 Microsoft Entra 新功能，涵盖单点登录策略、云同步写回能力、生命周期工作流增强等关键场景。这些更新旨在提升企业身份与访问管理基础设施的管控效率与隐私保护水平。

![](https://cdn.neowin.com/news/images/uploaded/2025/07/1751438716_microsoft-entra-id_story.webp)

### **Windows 11 SSO 自动审批策略**

IT 管理员现可通过全新的 Windows 11 注册表策略，在托管的 Entra ID 设备上自动批准单点登录（SSO）。该功能随 **2026 年 7 月 Patch Tuesday** 更新推送，为管理员提供了更精细的访问控制能力。

### **Entra Cloud Sync 写回能力**

Entra Cloud Sync 新增写回功能，支持将 Exchange Online 的关键属性变更同步回本地 Active Directory。与此同时，Entra External ID 现允许在联合注册至外部身份提供商时隐藏用户电子邮件地址，显著增强企业隐私保护。

### **Lifecycle Workflows 增强**

生命周期工作流新增 What-if 模拟模式，可预判工作流执行范围并识别潜在问题。管理员现可取消正在运行的工作流，并为生命周期事件配置最多 **10 个属性**的自动设置或清除操作。此外，自定义邮件现已支持新的属性格式与扩展的动态属性集。

### **公共预览功能**

微软同时开放了三项功能的公共预览：本地 Active Directory 设备与 Microsoft Entra Cloud Sync 的同步、生命周期工作流中无赞助人访客账户的自动检测与清理，以及 Microsoft Entra Domain Services 中组策略对象（GPO）的备份与还原能力。
