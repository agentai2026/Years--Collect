简介：一个免安装的单文件批处理工具(14KB),把 Windows 里最常用又最分散的电源设置收进一个面板，不用再钻多层控制面板菜单。管理员运行即可可视化修改屏幕熄屏、休眠时间，自定义电源键 / 盒盖动作，一键切换高性能、卓越性能、节能方案，开关快速启动，不用一层层点控制面板。

功能一览：
屏幕关闭 / 系统睡眠超时(电池 / 接通电源 四项独立设置，0 = 从不)电源按钮、关盖子动作(不动作 / 睡眠 / 休眠 / 关机)快速启动一键开关(写注册表 HiberbootEnabled,关闭后关机更彻底)单独修改电池 / 插电模式下：屏幕关闭时间、系统睡眠时间，支持一键全部设为「从不」高性能 / 平衡 / 节能一键切换，卓越性能自动解锁(家庭版可用，防重复解锁)全部操作实时回显实际生效值，不做假成功附带操作提示，标注休眠开启命令，新手也能看懂

使用说明：
下载解压，双击运行(修改类操作建议右键“以管理员身份运行”)按数字/字母选择对应项目，输入数值回车即可，直接回车刷新
