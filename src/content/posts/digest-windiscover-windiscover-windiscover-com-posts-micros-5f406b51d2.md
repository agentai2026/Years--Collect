微软发布 Microsoft Defender 安全更新，面向 Windows 11、Windows 10 及 Windows Server 的 ISO 安装镜像。本次安全情报更新版本号为 **1.455.50.0**，旨在解决系统安装过程中存在的临时安全防护缺口。

![](https://cdn.neowin.com/news/images/uploaded/2025/06/1750541509_microsft_defender_neowin_story.webp)

### **更新版本与覆盖范围**

本次更新包含三个核心组件升级：平台版本升级至 **4.18.26070.9**，引擎版本升级至 **1.1.26070.7**，安全情报版本为 **1.455.50.0**。该更新包适用于 Windows 11、Windows 10 ESU、Windows 10 Enterprise LTSC 2021、Windows 10 Enterprise LTSC 2019、Windows 10 Enterprise LTSB 2016、Windows Server 2022、Windows Server 2019 及 Windows Server 2016 的安装镜像。

### **安全防护缺口修复**

Windows 安装镜像可能包含过时的反恶意软件定义和二进制文件，导致新系统安装完成后存在临时安全风险。微软表示，这些更新定义有助于关闭这一保护缺口，确保系统在首次启动时即具备最新的安全防护能力。

### **威胁检测能力更新**

根据微软安全公告，此前发布的 **1.447.236.0** 版本（上月早期发布）已新增对多种恶意软件的检测能力，包括木马、后门漏洞利用程序、勒索软件、窃取器及 AutoKMS 等。截至发稿时，最新的安全情报更新版本为 **1.457.181.0**。
