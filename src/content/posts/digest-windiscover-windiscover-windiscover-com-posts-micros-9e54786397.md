微软正式推出 Microsoft Classroom，一款专为教育机构的独立学习应用，将现有教育工具整合至统一界面。该应用支持 Web、桌面及移动端访问，内置 AI 驱动的学习助手，预计于 2027 年初开放预览。

![](https://cdn.neowin.com/news/images/uploaded/2026/11/1794412880_microsoft_classroom_full.webp)

### **功能定位与工具整合**

Microsoft Classroom 旨在提供专注于教学与学习的专用体验，而非替代现有的 Microsoft Teams for Education。它将 Assignments、Classwork、Grades、Class Notebooks 和 Learning Accelerators 等核心教育工具聚合至单一入口。学校仍可继续使用 Teams 或通过 Microsoft 365 LTI 将教育工具集成至现有学习管理系统。

![](https://cdn.neowin.com/news/images/uploaded/2026/11/1794412880_microsoft_classroom_story.webp)

### **分级教育场景支持**

应用针对三个教育阶段提供差异化功能：高等教育学生可从单一路径追踪多课程作业进度；中学教师能统一管理多个班级并快速访问 OneNote Class Notebook；小学则提供简化界面帮助学生专注学习内容而不受干扰。

### **个性化主页体验**

教师可创建独立的 Class Home 页面，自定义布局以适应教学需求。学生将获得展示待办作业、逾期任务及教师反馈的个人首页，教师端则显示待批改作业与跨班级活动概览。

### **AI 功能与部署架构**

Study and Learn Agent 等现有 AI 教育工具将直接集成至应用内。底层沿用 Microsoft 365 Education 基础架构进行身份管理与数据存储，同时支持 School Data Sync 自动同步班级与学员名录。
