微软为 Windows 11 25H2 和 26H2 版本发布了两项动态更新，分别是更新程序优化与安全操作系统环境改进。这两项更新将通过 Windows Update 通道自动下载并安装。

![](https://cdn.neowin.com/news/images/uploaded/2025/11/1763354538_windows_11_update_4_1_full.webp)

### **KB5135609 更新程序动态更新**

此版本针对 Windows 11 版本 25H2 和 26H2 在功能更新中使用的 Windows 设置二进制文件或相关文件的安全漏洞进行了修复。该更新属于 Setup Dynamic Update 类别，专门用于现有 Windows 镜像部署前的改进。

动态更新包会在升级过程中帮助保留语言包（LP）和需求功能（FODs）内容，例如 VBScript 目前在 Windows 11 24H2 及更高版本上作为 FOD 存在。

### **KB5133853 安全操作系统动态更新**

此更新针对 Windows 恢复环境（WinRE）进行改进。安装后，设备上安装的 WinRE 版本应为 10.0.26100.10074。

![](https://cdn.neowin.com/news/images/uploaded/2025/11/1763354538_windows_11_update_4_1_story.webp)

### **更新时间与部署方式**

两项动态更新均于 2026 年 11 月 19 日发布。微软说明恢复更新和设置更新将通过 Windows Update 通道自动下载和安装，用户无需手动干预。

上周微软已发布了 KB5132057 和 KB5132265 作为 11 月的可选预览更新，同时还有新的 OOBE 初始设置更新 KB5134999 和 KB5135000 可供受支持的 Windows 11 系统使用。

### **影响范围与意义**

此次更新主要面向 Windows 11 25H2 和 26H2 版本，涉及设置文件二进制体的修改和安全操作系统的优化。动态更新机制确保镜像部署前能获得最新的稳定性和安全性改进。
