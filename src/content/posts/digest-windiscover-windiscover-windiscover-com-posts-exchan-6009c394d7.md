微软宣布 Exchange Online 的旧版电子邮件 Web 服务（EWS）API 将于 **2026 年 4 月 1 日**正式停用，依赖该接口的第三方应用和服务可能面临邮件同步功能中断的风险。企业需在截止日期前完成向 Microsoft Graph API 的迁移。

![](https://storage.windiscover.com/files/ews-deadline-feature.png)

### **EWS API 停用的背景与影响**

EWS 是微软 Exchange 系列产品的早期电子邮件服务协议，随着云服务架构演进，其安全性和可扩展性逐渐无法满足现代需求。自 Office 365 转型以来，微软持续推动客户迁移至更新的 API 接口。此次停用将直接影响全球数百万企业的邮件系统集成方案，尤其是依赖 EWS 的第三方邮件客户端、自动化工具及定制化开发应用。

### **迁移路径与技术支持**

微软已发布官方迁移指南及工具包，协助组织评估现有 EWS 依赖并规划升级方案。推荐企业优先采用 Microsoft Graph API，该接口提供更全面的功能覆盖与安全性保障。对于无法立即切换的场景，微软提供并行运行策略以保持兼容性。
