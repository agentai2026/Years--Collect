## 我写了一个「B站动态筛选助手」：让关注的几百个 UP 主，按分组和标签看

### 一、先说痛点

玩 B 站久了，关注列表迟早会膨胀到几百上千人。

B 站本身是有「关注分组」的，你可能也认真分过：学习区、游戏区、生活区、摄影区……但问题在于——**分组只能在关注页看，动态流里根本用不上**。打开 `t.bilibili.com`，首页动态永远是所有 UP 混在一起的大杂烩，你分的组形同虚设。

更烦的是：

- 想安安静静看某一类 UP 的动态，做不到；

- 某个 UP 天天刷屏，又舍不得取关，只能忍着；

- 动态页塞满了直播区、发布框、话题榜、我的信息……真正看动态的区域被挤得很小。

所以我写了一个油猴脚本，专门解决这几件事。它叫 **B站动态筛选助手**。

### 二、它能做什么

#### 1. 按「关注分组」聚合查看动态（核心功能）

在动态页左侧注入一个悬浮面板，把你在 B 站分好的关注分组直接搬过来。

- 点某个分组，动态流里**只留下这个组内 UP 的动态**，其他人的自动隐藏；

- 分组按钮上会显示 `分组名 (N)`，N 是**当前已加载动态中**该组活跃的 UP 数，一眼就能看出哪个组有更新；

- 不用取关、不用退订，纯粹是"看的时候过滤"，随时点「全部」还原。

#### 2. 自建「标签」，比原生分组更灵活

B 站的关注分组是"一个人只能属于一个组"，但现实里一个 UP 常常横跨多个兴趣。所以脚本支持自己建标签：

- 一个标签可以同时绑定「某个分组」和「若干单个 UP 主」；

- 想临时组一个"最近爱看"的清单，几秒钟就能建好；

- 标签数据存在本地，想删就删。

#### 3. 「不想查看」屏蔽名单

有些 UP 不想看，但又不至于取关（比如偶尔还是想看）。脚本提供屏蔽功能：

- 支持**屏蔽 7 天**或**永久屏蔽**；

- 屏蔽后，该 UP 的动态在分组、标签、全部等所有模式下都不再出现；

- 在「不想查看」页可以随时点「取消屏蔽」恢复。

#### 4. 右栏 UP 名单，一键看单人动态

右侧列出当前动态里出现过的 UP，点一下就能切到他的个人动态（复用的是 B 站原生切换逻辑，行为和你手动点一致）。左栏筛选与右栏单人查看是互斥的，点左栏任意一项即可切回聚合视图。

#### 5. 界面净化

打开动态页，脚本会自动清理掉这些干扰区块：

- 顶部"发布动态"输入框；

- "我的信息"卡片；

- 直播区；

- 右侧话题榜；

- 原生 UP 主头像列表（**只是隐藏，不是删除**，因为切换 UP 还要靠它）。

留在屏幕上的，基本只有动态本身，视野清爽很多。

#### 6. 一键「加载 50 条动态」

动态页默认是滚动到底自动加载。脚本在面板标题旁放了一个按钮，点击后**直接调用页面自身的加载逻辑**，累计多加载约 50 条动态，不用你一屏一屏地滚。

配合分组/标签筛选特别好用：先加载足够多的动态，再按分组过滤，样本更全。

#### 7. 筛选时不再"无限触底加载"

开启分组或标签筛选后，脚本会在列表底部撑出空白，阻止 B 站继续自动加载。

这带来一个很符合直觉的行为：**你看到的就是"已加载范围内"该分组的人**，列表底部会提示「「分组名」到底了」，不会滑着滑着又混进来一堆新动态。

### 三、安装方法

#### 第 1 步：安装油猴扩展

浏览器安装 **Tampermonkey（篡改猴）** 扩展（Chrome / Edge / Firefox 应用商店均有）。

#### 第 2 步：安装拓展

[https://greasyfork.org/zh-CN/scripts/598851-b%E7%AB%99%E5%8A%A8%E6%80%81%E7%AD%9B%E9%80%89%E5%8A%A9%E6%89%8B](https://greasyfork.org/zh-CN/scripts/598851-b%E7%AB%99%E5%8A%A8%E6%80%81%E7%AD%9B%E9%80%89%E5%8A%A9%E6%89%8B)

#### 第 3 步：确认已登录 B 站

脚本需要读取你的关注分组，请确保浏览器已登录 B 站账号。

>
说明：脚本的所有数据（分组、标签、屏蔽名单）都保存在你本地的油猴存储里，不会上传到任何服务器。

### 四、使用教程

#### 第一步：先获取关注分组

打开 **关注页**：`https://space.bilibili.com/你的UID/relation/follow`

页面会出现「获取分组」按钮，点一下，脚本会去拉取你的关注分组和组内成员，并缓存在本地。

- 之后按钮会变成「更新分组」，关注列表有变动时点它刷新即可；

- 也可以在 Tampermonkey 的脚本菜单里点「获取关注分组（控制台输出）」。

#### 第二步：回动态页开始用

打开 **动态页** `https://t.bilibili.com/`，左栏会出现「B站动态筛选助手」面板，包含三个页签：

**分组查看**：点任意分组，动态流立即只剩该组 UP 的内容；点「全部」还原。未获取分组时会提示"请先到关注页点击「获取分组」"。

**标签查看**：点「＋ 新建标签」，填写标签名，选择要包含的分组和 UP 主，保存即可。之后点标签就能按它筛选。

**不想查看**：列表展示已屏蔽的 UP，可选择「屏蔽 7 天」或「永久屏蔽」；已屏蔽的可点「取消屏蔽」。

#### 第三步：加载更多 + 筛选

先点面板标题旁的「加载 50 条动态」，多攒一些动态，再点分组或标签查看，效果最好。

### 五、常见问题

**Q：面板提示"请先到关注页点击「获取分组」"？**

A：分组数据需要先在关注页获取一次，之后才能在动态页使用。

**Q：新关注的 UP 没出现在分组里？**

A：回关注页点「更新分组」重新拉取。

**Q：分组按钮显示 `(0)`？**

A：括号里的数字只统计**当前已加载动态**中该组活跃的 UP。先点「加载 50 条动态」或多滚动几屏，数字就会出现。

**Q：点了右栏的 UP，左栏怎么切回去？**

A：点左栏的「全部」或任意分组即可切回聚合视图。

**Q：控制台出现"无法在当前网页中找到相应节点"或 Mixed Content 警告？**

A：这两条都来自 B 站页面自身的代码（表情图片 http 自动升级等），与脚本无关，不影响使用。

**Q：加载 50 条后滚动条没变化？**

A：脚本调用的是页面自身的加载逻辑，列表内容会增加；若页面本身已加载到底，则不会有新内容。

### 六、写在最后

这个脚本的出发点很简单：**把 B 站已有的"关注分组"真正用起来**，让动态流从"信息瀑布"变成"可以自己决定看什么"。

目前的实现思路是"不改变 B 站原生行为，只做展示层的筛选与隐藏"：该隐藏的隐藏，该保留的保留（比如切换 UP 用的列表只是隐藏而非删除），尽量不影响原有功能。

如果你也有关注列表爆炸的困扰，欢迎试试。使用中遇到问题或有想加的功能，可以在评论区告诉我。
