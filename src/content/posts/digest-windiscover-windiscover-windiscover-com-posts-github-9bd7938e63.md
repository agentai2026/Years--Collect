微软确认 GitHub 服务器发生严重故障，导致平台几乎所有服务目前无法正常运行。用户访问网页端、API 接口及核心功能均出现高错误率，GitHub Status 官方账号已发布多轮事件通报。

![](https://cdn.neowin.com/news/images/uploaded/2025/08/1754930428_github_ceo_microsoft_story.webp)

### **故障范围与影响**

本次故障波及 GitHub 全线服务。根据 GitHub Status 官方通报，网页体验与 API 流量错误率约为 **20%**，归档下载与原始仓库内容下载错误率高达 **50%**。此外，SAML 与 OIDC 认证、SCIM、Team Sync、Copilot 智能编码助手、Issues 问题追踪等核心功能均出现可用性降级或完全中断。Pull requests 代码合并请求同样受到影响。

### **事件时间线**

故障最初表现为高错误率，随后在过去一小时内逐步演变为全面服务中断。GitHub Status 官方账号在 **8 月 17 日** 连续发布多条推文，实时更新各项服务的受影响状态，并表示正在调查根本原因。

### **后续跟进**

截至目前，GitHub 尚未公布故障的具体原因及预计恢复时间。微软与 GitHub 工程团队正在持续调查，官方承诺将在获得更多信息后提供进一步更新。
