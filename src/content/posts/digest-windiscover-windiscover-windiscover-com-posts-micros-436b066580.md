微软已决定终止 Windows 11 的 Drop Tray 功能开发，该功能在经过一年多的测试与多次调整后正式退出。目前这项移除变更已出现在最新发布的 Windows 11 Insider 版本中，微软官方表示该决定主要基于用户反馈。

![](https://cdn.neowin.com/news/images/uploaded/2026/03/1772392997_windows_11_logo_neowin_story.webp)

### **功能演进历程**

该功能最初以 Drag Tray 的名称于 2025 年 2 月随 Windows 11 Beta Build **22635.4950** 推出。用户可将本地文件拖拽至屏幕顶部，系统会弹出应用推荐栏和 Windows 分享面板选项。由于初期测试反馈不佳，微软对该功能进行了多次调整：年初因用户抱怨误触问题缩小了界面尺寸；2025 年 3 月随 Beta Build **26220.8062** 将其更名为 Drop Tray，并将开关移至设置 > 系统 > 多任务处理路径下。修订版本于同年春季通过可选预览更新向普通 Windows 11 用户推送，但并非所有设备均可使用。

![](https://cdn.neowin.com/news/images/uploaded/2026/08/1787053140_drop_tray_windows_11_story.webp)

### **用户反馈与设计冲突**

Drop Tray 自推出以来反响欠佳。尽管功能初衷合理，但用户普遍反映其实际体验笨拙且不稳定。该托盘占据屏幕顶部边缘，与用户在 File Explorer 标签页之间拖拽文件或向最大化窗口拖放文件的常用操作区域重叠。用户投诉称该界面可能在正常的拖拽工作中意外弹出造成干扰，这也解释了微软此前决定缩小其尺寸的原因。

### **后续安排与替代方案**

由于持续收到负面反馈，微软开发团队最终决定终止该项目。鉴于该变更目前仅在 Insider 版本中宣布，普通用户需等待后续更新才能彻底移除该功能。微软同时表示仍在探索其他本地文件分享方案，未来可能推出类似功能。目前用户仍可通过 Phone Link 将文件发送至已连接的手机，或通过 Link to Windows 应用实现反向传输。
