开发者 Justin Marshall 完成了一项复古软件移植项目，将微软1990年发布的 Word for Windows **1.1a** 转换为原生64位 Windows 可执行文件。该版本基于微软2014年开源的原始代码，可在 Windows 11 上直接运行，无需模拟器。

![](https://cdn.neowin.com/news/images/uploaded/2026/08/1786172511_windows_3.0_story.webp)

### **项目背景与技术实现**

Word for Windows 1.1a 于1990年发布，是 Word 1.0 的第二次更新，也是 Word 首次登陆 Windows 平台的早期版本之一。此前，Word 仅在 MS-DOS 系统上可用。该移植项目采用微软于 **2014** 年开源的原始代码，通过重新编译使其成为完整的64位 Windows 应用程序。

![](https://cdn.neowin.com/news/images/uploaded/2026/08/1786171652_word_1.1a_port_story.webp)

### **功能特性与界面设计**

移植后的版本完整保留了1990年代的软件体验：界面中没有 Copilot 按钮、云存储、精美设计模板等现代功能，仅提供基础的文档编辑与简单格式选项，呈现典型的早期 Windows 设计语言。用户可获得一张虚拟纸张和少量工具栏选项，界面简洁程度与当前 Microsoft 365 生态形成鲜明对比。

### **开发者与其他项目**

Justin Marshall 长期致力于复古软件与游戏在现代硬件上的复活工作。其 GitHub 主页还托管了多个类似项目，包括将 Quake 4 SDK 与 Doom 3 引擎融合的 Quake4Doom，以及使用 idTech 4 引擎和泄露资源重制的 Duke Nukem Forever。

### **获取方式**

该移植项目已开源，用户可通过 [GitHub](https://github.com/jmarshall23/msword) 下载体验。项目为希望重温早期 Windows 办公软件体验的用户提供了原生运行方案，也为软件历史研究者提供了可直接执行的原始代码样本。
