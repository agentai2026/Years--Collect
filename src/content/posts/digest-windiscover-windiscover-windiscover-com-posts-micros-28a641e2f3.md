微软正在推进年龄验证系统的全面部署，近期曝光的支持文档确认 Teams Free 和部分 Windows 11 应用将面临基于年龄的功能限制。这项改动将影响到用户账户的体验完整性，新规范预计随着 Windows 11 26H2 正式版本推出而生效。

![](https://cdn.neowin.com/news/images/uploaded/2022/06/1654793970_2-ventura-bloom-dark.jpg)

### **Teams Free 体验差异化**

根据微软新发布的 Teams Free 支持页面，特定区域用户需要通过 Microsoft 账户完成年龄验证才能保留完整服务体验。未完成的账户将失去会议录制、Copilot 等 AI 功能以及社区功能的访问权限。微软表示此举旨在遵守各地法律法规要求。

### **未成年人额外限制**

被识别为未成年人的用户将面临更多限制，包括无法加入或创建 Teams Communities，且账号可发现性受到保护——默认情况下他人无法通过电话号或邮箱搜索到未成年人账户，除非本人主动开启可见性。

### **Windows Age API 技术规范**

微软同步公开了 Windows Age API 文档，该接口允许应用程序查询用户的年龄段（**未满 10 岁**、**10-12 岁**、**13-15 岁**、**16-17 岁**、**18 岁及以上**）及验证状态。系统不会向应用暴露出生日期等个人信息，仅返回宽泛年龄段信号以协助合规控制。

### **实施时间表与依赖条件**

文档明确指出这些 API 将在今年晚些时候的未来版本中启用，预计于 **Windows 11 26H2 公共版本发布**前后开始对用户可见。API 运行要求设备为 Windows 11、用户已登录 Microsoft 账户，且应用已在 Microsoft 数字安全平台注册身份标识。

### **全球年龄标准差异**

微软内部列表显示各国法定年龄限制存在差异：**印度为 18 岁**，**美国和英国为 13 岁**，其他地区有各自阈值。这种差异性导致微软无法为全球账户统一设置单一策略。
