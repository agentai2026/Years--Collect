第三方工具 WinPOPBit（前称 POP4.2）计划推出新版本补丁，使 Windows 11 能够在更早期的 AMD 和 Intel 处理器上运行。开发者已透露将对 Windows 11 23H2 进行专项适配，覆盖部分 2003 年发布的芯片。

![](https://cdn.neowin.com/news/images/uploaded/2023/12/1703046591_windows_11_intel_full.jpg)

### **AMD 平台扩展支持**

新版本补丁将支持 AMD 64 位 K8 架构处理器，包括采用 Socket 754、940、939 及 AM2 接口的早期 Athlon 64 X2 型号。此举意味着部分双核处理时代设备可能获得 Windows 11 安装能力，尽管微软长期推动 TPM 2.0 与 Secure Boot 要求。

![](https://cdn.neowin.com/news/images/uploaded/2026/11/1794756628_win_11_23h2_pentium_4_x.webp)

### **Intel 经典架构纳入范围**

WinPOPBit 还将为 Intel Prescott 核心的 Pentium 4 与 Smithfield 核心的 Pentium D 提供支持，均采用 LGA 775 接口。值得注意的是，现有 SSE4.2 绕过方案已适用于 Windows 11 24H2 及以上版本，而新补丁则聚焦于 23H2 的兼容性优化。
