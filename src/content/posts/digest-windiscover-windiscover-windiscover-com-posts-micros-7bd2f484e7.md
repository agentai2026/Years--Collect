微软近期展示了如何利用 AI 技术简化 Windows 应用的现代化流程。通过 GitHub Copilot 的现代化工具，开发者可将基于 .NET Framework 的旧版应用自动升级至 **.NET 10**，大幅降低手动重构的工作量。

![](https://cdn.neowin.com/news/images/uploaded/2024/07/1720468663_windows_11_story.jpg)

### **AI 辅助开发工具概览**

微软官方文档已将 WinUI agent 插件推荐给 Windows 开发者。该插件支持在 GitHub Copilot 或 Claude Code 中完成端到端的 WinUI 应用开发。此外，微软还提供 AI 辅助测试功能，可利用 Windows UI Automation 生成并运行 UI 测试。

![](https://cdn.neowin.com/news/images/uploaded/2026/08/1787486985_ai_assisted_windows_development.webp)

### **GitHub Copilot 现代化工作流**

微软在博客中演示了 BookCatalog 应用的升级过程。开发者只需在 Visual Studio 中右键点击项目并选择 “Modernize” 选项，Copilot 现代化代理便会自动执行任务。

![](https://cdn.neowin.com/news/images/uploaded/2026/08/1787486998_modernize-01-bootcatalog_story.webp)

### **分阶段检查点机制**

该工具采用检查点机制，开发者可在每个阶段审查 AI 的发现和拟议修改。Copilot 基于分析结果生成升级计划，开发者确认后，代理按顺序完成各项任务。在演示案例中，整个升级过程共完成 **5 项任务**。

![](https://cdn.neowin.com/news/images/uploaded/2026/08/1787486991_modernize-15-complete.webp)

### **技术限制与后续工作**

微软明确指出，现代化代理不会重新设计应用的 UI 界面。升级后的应用在视觉上与原版保持一致，开发者仍需手动处理视觉层面的翻新工作。不过，结合 WinUI agent 工具，开发者可在框架升级完成后继续进行界面现代化。
