微软向 Windows 高级用户推出了 Windows Package Manager (WinGet) 新版更新。新版本引入实验性交互式包选择功能，允许通过数字编号快速安装应用。

![](https://cdn.neowin.com/news/images/uploaded/2022/08/1659609107_windows_package_manager_winget_full.jpg)

### **交互式包选择功能详解**

新版 WinGet **1.30.310** 引入实验性交互式包选择功能。当搜索多个匹配项时，系统会为每个软件包分配编号，用户只需输入对应数字即可完成安装，若输入 0 则可取消操作。

### **适用场景与限制**

该功能兼容 show 和 download 命令，但仅适用于直接交互场景。自动化脚本不会受到影响，因为此特性仅在手动使用时生效。

### **配套更新内容**

此次更新还支持设置包源优先级，并新增 –output-locale 参数以调整界面语言。这些改进提升了工具的可配置性与多语言支持能力。
