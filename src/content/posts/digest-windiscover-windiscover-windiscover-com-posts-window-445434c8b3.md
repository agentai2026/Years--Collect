微软于本周 Patch Tuesday 期间发布了针对 Windows 11 和 Windows 10 的 Safe OS 动态更新，重点改进 Windows Recovery Environment（WinRE）恢复环境。本次更新以独立补丁形式推送，覆盖多个 Windows 版本。

![](https://cdn.neowin.com/news/images/uploaded/2025/11/1763354538_windows_11_update_4_1_story.webp)

### **更新版本与适用系统**

本次发布的 WinRE 更新包含以下四个补丁：

- **KB5120999**：面向 Windows 11 26H1，更新后 WinRE 版本号为 **10.0.28000.2703**

- **KB5121002**：面向 Windows 11 24H2 和 25H2，更新后 WinRE 版本号为 **10.0.26100.9168**

- **KB5120250**：面向 Windows 11 23H2，更新后 WinRE 版本号为 **10.0.22621.7516**

- **KB5120248**：面向 Windows 10 21H2 和 22H2，更新后 WinRE 版本号为 **10.0.19041.7660**

### **动态更新技术说明**

Safe OS 动态更新（Dynamic Update）主要用于在系统部署前对现有 Windows 镜像进行优化。该类更新包含 WinRE 恢复环境改进及安装程序二进制文件（Setup）更新，同时可在升级过程中保留语言包（LP）和按需功能（FOD）内容。微软表示，恢复更新将通过 Windows Update 通道自动下载和安装。
