微软正式确认 Windows Management Instrumentation Command-line（WMIC）工具将在 Windows 11 的下一个功能更新中被彻底移除。该工具自 **2001** 年随 Windows XP 发布以来已存在约 25 年，主要用于 IT 管理员通过命令行与 WMI 交互以管理 PC 软硬件。

![](https://cdn.neowin.com/news/images/uploaded/2024/01/1706314378_wmic.jpg)

### **移除时间表与版本规划**

微软在 Release Preview 版本 **26100.9267** 和 **26200.9267**（对应 Windows 11 24H2 和 25H2）的更新说明中确认，WMIC 将在 **2026 年 8 月**后不再包含于 Windows 11 中。由于该 Release Preview 版本最终将作为 Windows 11 **version 26H2** 向普通用户推送，这意味着 WMIC 将不会出现在该版本中，且不再作为按需功能（Feature on Demand）提供。

### **弃用历程回顾**

微软对 WMIC 的弃用已持续多年。该工具于 **2016** 年在 Windows Server 中被标记为弃用，随后在 **2021** 年扩展至 Windows 10，并在 Windows 11 中默认禁用。尽管用户仍可通过按需功能方式安装，但微软已明确表示下一代 Windows 将不再提供该组件。

### **替代方案与迁移建议**

微软推荐的替代方案是使用 Windows PowerShell 进行 WMI 操作，PowerShell 提供了与 WMIC 类似但更强大的功能。对于仍在使用 WMIC 脚本的管理员和用户，微软已在技术文档中提供了详细的迁移指南和替代命令参考。
